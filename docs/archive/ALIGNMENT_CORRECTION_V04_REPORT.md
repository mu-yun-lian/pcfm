# PCFM 对齐修正版 0.4

## 本轮真正接通

- 网页普通对话统一调用 `ResponsePredictionKernel`；内容预测阶段生成式 LLM 调用数固定为 0。
- 多头预测真实复用前期 `MapPersonEncoder`、`IdentityAdapterGenerator`、`DecisionIntegrator`；满足多人池门槛时可复用 `PopulationPriorEstimator`。
- 对话上下文显式包含当前话题、最近消息、关系、场合、时间范围、已表达主张和动态状态门禁。
- 每个人物版本生成独立表层风格工件；渲染只拼接冻结内容片段，并再次通过语义守门，失败返回中性内容。
- 名称搜索接入 Bing RSS。结果只保存为待核验 `reference_only` 候选，不会自动训练。
- 人物卡片提供编辑、导出与归档；归档支持说明、自动切换、短时撤销、计数、恢复及输入人物名称后的永久删除。
- 前后端暴露 `0.4.0-alignment-1` 版本；旧页面会提示刷新。

## 证据契约修复

训练标签只允许：

1. 有来源地址或文件、原始位置、上下文和明确说话人的逐字稿；
2. 同时绑定原文位置的已核验准确翻译。

编辑摘要、模型生成内容、搜索摘要和第三方转述被降为 `reference_only` 或 `unverified_candidate`。正式 Steve Jobs 中文编辑摘要已迁移为参考资料，旧 v1 标记为 `invalidated_evidence_contract`，当前版本置空。

## 暂不进入正式预测

- 动态状态：需要按时间排序、已验证且可签名的真实响应结果；系统生成聊天不能更新它。
- 认知特征和机制修正：自然语言响应事件尚未满足其可识别、可复算输入合同。
- HyperNetwork、Person-Issue、Joint Core：保留竞争模型，但此前未通过共同门禁，未恢复为默认模型。
- OCR、音视频转写和真实回答的在线全文抓取：尚未实现。

## 验收记录

- 聚焦行为测试：19 项通过。
- 完整回归：291 项通过，用时约 218 秒。
- 浏览器实际走通：创建人物、逐字材料导入、自动事件提取、审核、v1、两轮聊天、现实回答对照、pending 优化、独立留出、v2、回退 v1、归档、恢复、服务重启持久化、名称确认永久删除。
- 未勾选现实回答对照的零额外调用由自动化测试覆盖；浏览器验收人物在主动对照前完成两轮普通预测。
- 浏览器控制台没有页面错误。

## 不能宣称

工程闭环与证据门禁已通过测试；真实人物响应预测准确性、人物特异性增益、置信度校准和风格盲测仍未获得独立真实留出证据。Steve Jobs 当前材料不足，不能宣称已经建立可用人物响应模型。
