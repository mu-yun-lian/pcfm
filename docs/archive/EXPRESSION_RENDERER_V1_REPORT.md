# PCFM 受约束表达渲染层 v1 实施与验收报告

## 结论

本阶段已经把“人物说什么”和“怎样表达”拆成两个互不越权的接口。新增表达层只能接收 PCFM 上游冻结的内容合同，并生成轻度、标准、强辨识度三档表面改写；它不读取原始用户问题，不读取人物认知库、事实库或时间线，也不能独立回答问题。Steve Jobs 的完整 Nuwa Skill 仅作为材料审计对象和内容污染负对照，未进入运行时。

当前状态是 `implemented_exploratory`。结构化语义保持和内容污染门禁已经通过自动化测试；Steve Jobs 风格的独立盲测辨识度尚未验证；PCFM 人物响应预测准确性也不属于本阶段结论。

## 审计结果

### 保留

- 原有人物、本地存储、版本、证据、行为基线和认知工作台接口，作为表达层的上游或历史功能。
- Nuwa 的原始材料定位、表达分析方法、来源追踪方法和完整人物 Skill 对照。
- 原有网页框架与本地启动方式。

### 删除或禁止进入运行时

- 完整人物 `SKILL.md` 的身份扮演和自由回答路径。
- “你现在是 Steve Jobs”、思想模型、价值观、决策规则、人生经历、人物关系、时间线和公开立场等表达指令。
- 未经确认的启发式分类项和包含人物观点的完整示例回答。

这些内容没有从历史 Nuwa 目录物理删除，以便审计和复现；表达包加载器无法读取它们。

### 迁移

- 互动行为迁移为 PCFM 上游 `speech_act` 权威，表达层只能实现已经冻结的行为。
- 认知内容继续归 PCFM 人物模型。
- 人物事实继续归证据与人物记忆库；表达层只接收上游明确批准的 `memories` 文本。
- Nuwa 完整人物 Skill 迁移为敌意污染基线。

### 新增

- `pcfm.expression_renderer.ExpressionRenderer` 单一运行内核。
- 冻结内容合同校验、表达包密封校验、三候选生成、语义守门、回退选择和本地渲染记录。
- Steve Jobs 内部表达渲染包的七个文件，不含 `SKILL.md`。
- 网页中的冻结合同、三候选、规则来源、检查结果、污染拒绝和最终选择面板。

## 表达渲染包

路径：`src/pcfm/expression_profiles/steve_jobs_v1/`

- `style_manifest.json`：身份、版本、语料与适用范围、文件哈希、验证状态。
- `surface_rules.json`：只含闭集的前缀/连接方式等表层操作。
- `context_modes.json`：访谈、演讲、简短邮件三种场合和三档强度。
- `sanitized_examples.jsonl`：只保留内容槽位、句法骨架、节奏和修辞动作。
- `forbidden_mutations.json`：禁止新增主张、理由、事实、实体、数字、引语或改变否定、模态、置信度。
- `provenance.json`：每条已选规则的来源、位置、分类理由和审核状态。
- `style_tests.jsonl`：12 类敌意测试登记。

表达包由 manifest 中的 SHA-256 绑定。文件被修改后必须重新审核并密封；即使恶意规则被重新密封，运行时的闭集操作与危险内容检查仍会拒绝它。

## 冻结内容合同与守门

运行时只接受：`speech_act`、`claims`、`reasons`、`memories`、`uncertainties`、受保护实体/数字/引语、`confidence` 和上游指定的 `style_mode`。出现 `user_question`、`beliefs`、`values`、人物时间线等字段会直接拒绝。

当前渲染器使用受限模板，把每个锁定片段原样保留，只能在允许位置加入已审核的表层连接词。因此能够确定性检查：主张/理由/记忆/不确定项覆盖、新文本、受保护实体/数字/日期/引语、否定、模态词、置信度和结构化合同不变。强候选失败时依次退回标准、轻度，全部失败则输出中性版本。

“双向语义蕴含”当前是精确片段双向覆盖代理，不是经过验证的 NLI 模型。因果方向由理由片段原样保留而间接保证，尚未覆盖自由句法改写。网页会明确显示 `not_run_no_validated_nli_backend`，不会伪称已完成神经语义验证。

## 测试范围

新增自动化测试覆盖：

1. 三档候选与回退选择；
2. 空合同不产生观点；
3. 互相矛盾的合同不被改回人物常见立场；
4. 缺少经历或引用时不得发明；
5. 拒绝原始用户问题和认知字段；
6. 人名、数字、日期、否定、模态和置信度保持；
7. 调换人物包只改变表面文本；
8. 恶意或越权包被拒绝；
9. Nuwa 四分类与默认禁止规则；
10. 完整人物 Skill 污染探针即使风格分更高也被拒绝；
11. 20 轮连续渲染中内容权威始终属于 PCFM；
12. 表达包哈希、候选检查和本地记录可重算；
13. 网页 HTTP 完整闭环。

## 浏览器实际验收

在 `http://127.0.0.1:8767/` 的真实浏览器页面中使用内置冻结合同完成一次流程。页面显示未风格化中性文本、轻度/标准/强三档候选、各候选使用的规则及来源、15 项结构化检查和最终选择。三档候选均保持 `Orchid Team`、数字 `17`、日期 `2027-04-03`、否定 `should not`、不确定性 `may` 和置信度 `0.64`，最终选择 strong。

完整人物 Skill 污染探针加入了新名言和新观点，虽然表层指纹更高，仍以 `new_claim_or_unapproved_text` 和 `bidirectional_entailment_proxy` 失败被拒绝。页面明确显示 NLI 未运行、风格盲测未完成、人物响应预测准确性未评估；浏览器控制台无警告或错误。结构化验收记录见 `artifacts/expression_style_v03/browser_acceptance.json`。

全量回归结果：`266` 项测试全部通过，耗时 `205.683s`。

模块门禁审计没有被人为改成“确认性通过”。它只剩两项拒绝原因：模块状态仍是 `implemented_exploratory`，以及尚不存在预先冻结的未来/盲测留出集（`future_holdout=false`）。这正对应当前无法证明人物特异性风格辨识度的限制。

## 剩余限制

- 当前只支持英语和三种公开表达模式。
- 表层规则主要是可审计的连接词与节奏骨架，辨识度有限；没有训练可学习的人物风格适配器。
- 本地 Nuwa 材料包含二次研究摘要，并非全部都是完整原始逐字稿；因此来源绑定不等于语料完整或研究结论正确。
- 尚无其他真实人物表达包，不能完成“删除姓名后的跨人物盲测”。
- 尚无独立人工评分者或冻结风格分类器，不能宣称 Steve Jobs 风格辨识度通过。
- 尚无经过验证的本地 NLI 后端；扩展到非模板自由改写前不能沿用当前门禁结论。

因此本阶段只证明：在当前受限表达操作与测试范围内，系统能在不改变冻结预测内容的前提下生成可追溯的表层风格候选。它不证明系统已经学会 Steve Jobs 的思想，也不证明 PCFM 能准确预测他的下一次回应。
