## 二、关键改动

### P0 问题 A：db.transaction() 异常传播
- `persistence/db.py`：`commit()` 失败不再 `pass`，改为 rollback 后 `raise`。
- 所有 `_sync_*_to_sqlite` 均被 `except Exception → warning` 包裹，故同步失败只告警、不崩主流程。

### P1 问题 B：版本同步 delete + upsert
- `version_repo.delete_by_person_no_commit` + `_sync_versions_to_sqlite` 事务内先删后插，与 source/session 一致。

### P1 问题 C：归档前确保 person 行存在
- `delete_person` 在 `mark_archived` 前先 `_ensure_person_in_sqlite`，旧库/未迁移场景也能落到 health=archived。

### P1 问题 D：恢复时 SQLite 同步不阻断
- `restore_person` 文件恢复优先，`person_repo.upsert` 失败只记 warning、不抛错。

### P2 支线 3：评估类倾向 target 语义
- `simulation_v4.py`：`clean_tradeoffs` 与 `preference_atoms` 保留 `target_span`（实体）。
- `simulation_v5.py`：投影匹配改按 `target_span`（实体）匹配，`target`（类别）回退。
- `test_tendency_extraction_v1.py`：fixture 改为 `target=individual`（类别）+ `target_span=the Republican nominee`（实体），同语言同实体提问，移除 skip。
