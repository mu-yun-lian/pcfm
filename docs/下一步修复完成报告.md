## 一、T1–T6 落地清单

### T1 修复现实回答同步不可达
- 问题：`find_conversation_reality_answer` 在 `return result` 之后才执行 `_sync_messages_to_sqlite`，导致该同步永远不可达。
- 修复：把 `_sync_messages_to_sqlite(person_id)` 移到 `return` 之前（`src/pcfm/services/conversation_service.py`）。
- 效果：现实回答查找完成后，`message` 表的 `comparison` 与 JSON 一致。

### T2 会话 CRUD 同步 session 表 + 删除会话清理 message
- `start_new_conversation` / `create_conversation` / `switch_conversation` / `rename_conversation` 均补上 `_sync_sessions_to_sqlite`。
- `delete_session` 改为：`message_repo.delete_by_session_no_commit` 清理该会话消息 + `_sync_sessions_to_sqlite`，消除孤儿消息。
- 文件：`src/pcfm/services/conversation_service.py`、`src/pcfm/persistence/repositories/message_repo.py`。

### T3 migrate/rollback 补全 conversation_state 及六表清空
- `migrate_to_sqlite.py` 的 migrate() 现在写入 person/source/version/session/message/conversation_state 六表。
- rollback() 清空全部六表并返回各表计数。

### T4 删除 list_full_by_person 死代码
- 删除 `version_repo.list_full_by_person`（读路径已回退到 JSON，该 SQLite 读方法无调用方）。
- 文件：`src/pcfm/persistence/repositories/version_repo.py`。

### T5 同步函数事务化(no_commit + db.transaction)
- `_sync_sources_to_sqlite` / `_sync_versions_to_sqlite` / `_sync_sessions_to_sqlite` / `_sync_messages_to_sqlite` 统一走 `db.transaction()` + 各 repo 的 `*_no_commit` 方法，同步失败时无部分更新。
- `db.transaction()` 的 commit/rollback 各自包裹 try/except，容忍 Python 3.14 sqlite3 的良性告警（"cannot commit - no transaction is active" 等），不影响正确性。

### T6 创建人物公开搜索异步化
- 删除 `create_conversation_person` 内同步的 `collect_public_sources` 调用；创建时只保留 `collection.status = "search_ready"`。
- 前端 `createPerson`（`src/pcfm/web_static/src/stores/app.ts`）在 `source_mode === 'system_search'` 时创建完成后触发 `/conversation/search` 任务并 pollJob。
- 效果：创建人物请求不再阻塞于网络搜索。

## 五、额外修复：E2E 现实对照竞态

现象：E2E 归档步骤偶发 toast「消息不存在。」（而非「已移入归档」）。

根因：发消息后前端先渲染乐观占位消息（status=`generating`、message_id=`generating-…`），而「现实回答」按钮在此之前对所有助手消息无条件渲染。E2E 点击到占位消息时，把占位 message_id 发给后端 `find_reality_answer`，`_find_message` 找不到该消息即抛「消息不存在。」。

修复（提交 4a09007）：
1. `MessageList.vue`：生成中（generating）消息不再渲染「依据/现实回答/反馈」按钮。
2. `e2e/pcfm.spec.ts`：发送后等待助手真实答案（非「生成中…」）再做现实对照。
